# Privacy Profiling System (AI-Driven Westin Privacy Segmentation)

Vue 3 + Vite + Pinia + Vue Router, Firebase Authentication + Cloud Firestore, FastAPI backend (separate service).

```
npm install
cp .env.example .env     # VITE_DATA_MODE=mock works with no Firebase
npm run dev | npm run build | npm run preview | npm run test:logic
```
See **docs/SETUP.md** for Firebase setup, first-admin creation, security rules, the backend contract, and the live test checklist.
